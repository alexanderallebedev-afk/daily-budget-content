# daily-budget-content

Еженедельный «пакет» развлекательных выпусков для приложения «Б» (our-daily-budget.web.app).

- `packs/latest.json` — текущий пакет, его читает приложение (raw.githubusercontent.com).
- `packs/YYYY-wNN.json` — архив по неделям.

Пакет содержит только общий контент: никаких личных данных. Выпуски по данным пользователя собираются в самом приложении.

## Формат
```
{ "v":1, "week":"YYYY-MM-DD (понедельник)", "until":"YYYY-MM-DD", "city":"Москва",
  "episodes":[{ "id", "topic", "title", "theme", "days":[0-6]?, "from"?, "to"?,
     "slides":[{ "k":"надзаголовок", "t":"заголовок", "s":"текст", "art":"ключ иллюстрации",
                 "img":"wiki:ru:Название_статьи"?, "link":{"u","l"}?, "quiz":{"o":[...],"a":0,"why"}?,
                 "swatch":["#hex"]?, "end":1? }],
     "src":[...] }]}
```
Темы (`topic`): city, news, nature, art, recipe, quiz, holiday, selfcare, garden, design, joke, travel, music, movie, photo, meme, word, trend.
Иллюстрации (`art`): city, thread, eiffel, palette, film, sparkle, sun, turtle, owl, leaf, stars, comet, moon, pumpkin, pot, spoon, question, bread, wheat, breath, tulip, cup, heart, scale, cloud, rain, trophy, chart, dumbbell, wallet, fork, calendar, а также крупные картинки eye, pizza, donut, plate. Неизвестный ключ покажется как sparkle. Фон-фотография слайда: `"bg":"wiki:ru:Название_статьи"` (картинка статьи Википедии) или `"commons:Файл.jpg"`, подпись источника — `"cr"`. На таком слайде иллюстрация `art` не показывается, текст внизу поверх фото. Обложка выпуска в профиле берётся из содержания: фото первого слайда или самая говорящая иллюстрация; можно задать явно полем эпизода `"cover"` (ключ art или картинка wiki:/commons:). Короткая подпись под кружком в профиле: поле эпизода `"short"` — одно-два слова до 10 символов, по сути содержания («Звездопад», «Тыква», «Левитан»), а не название темы. Мемы: тема `meme`, слайд `{"k":"…","t":"","meme":{"img":"wiki:ru:Картина","t":"верхняя строка","b":"нижняя строка"}}` — известная картина из общественного достояния и своя подпись в стиле «классика + текст»; чужие мемы не копируем. Тема `photo` — красивые фотографии мест и природы. Тема `trend` — блюда, которые сейчас в тренде в рилсах; у слайда с блюдом поле `"dish":{"name":"Название","q":"основные продукты"}` — в приложении появится кнопка «В мои блюда», ИИ соберёт рецепт с калориями и его можно сохранить. Признак `"end":1` ставится на уровне слайда; последний слайд эпизода всегда считается финальным.

Темы оформления (`theme`): violet, sunset, mint, peach, sky, sun, gold, night, berry, forest.

Рецепт (тема `recipe`): на последнем слайде можно дать `"dish":{"name"}` и `"recipe":{"name","servings","minutes","yieldGrams","ingredients":[{"name","grams"}],"steps":[…],"per":{"grams","kcal","p","f","c"}}` — граммы ингредиентов на всё блюдо, `per` — на одну порцию (kcal ≈ 4·p + 9·f + 4·c). Кнопка «В мои блюда» сохраняет блюдо прямо из этих чисел, без ИИ.

## Идеи для тренировок
`ideas/library.json` — библиотека карточек-вариантов упражнений. Файл только пополняется: старые карточки не удаляются и не меняются, `id` уникальны и не совпадают со стартовым набором приложения.
```
{ "v":1, "ideas":[{ "id":"латиница-через-дефис", "name":"по-русски",
   "grp":"Ноги|Жим|Тяга|Плечи и руки|Пресс|Кардио",
   "base":["ключевые слова для поиска среди упражнений человека: присед, жим леж, подтяг…"],
   "goals":["сила","масса","жир","форма"], "kind":"w|bw|t|c",
   "img":"id папки из free-exercise-db (yuhonas/free-exercise-db, Unlicense)",
   "why":"1–2 предложения", "how":["3 коротких шага"], "equip":["…"],
   "added":"YYYY-MM-DD", "src":"ссылка на надёжный источник" }]}
```
`kind`: w — с весом, bw — свой вес, t — на время, c — кардио. Картинка: `https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/<img>/0.jpg`. Без видео.
